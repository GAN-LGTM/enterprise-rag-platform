## 七、自动化回归

**推荐：一条命令跑完**（无需外部服务的套件，退出码 0 即通过，可直接接入 CI）：

```bash
cd backend
python scripts/run_all_tests.py
# 需要服务已启动时，额外跑端到端套件：
RUN_E2E=1 python scripts/run_all_tests.py
```

也可单独执行：

```bash
python scripts/test_preflight.py     # 启动自检 13 项
python scripts/test_system_config.py # 系统信息接口 6 项
python scripts/test_optimize.py      # 能力回归 37 项
python scripts/test_doc_perm.py      # 文档权限与删除审批 14 项
python scripts/test_intent.py        # 意图识别准确性 30 项（层级优先级 / 会话补偿 / 安全降级）
python scripts/test_websearch.py     # 公网搜索脱敏与开关 13 项（脱敏 / 开关语义 / 节点门控）
python scripts/test_leave.py         # 请假工作流
python scripts/test_reimburse.py     # 报销工作流
```

全部套件退出码为 0（多数套件另会打印 `RESULT: ALL_PASS`，工作流类套件以 `结果：通过 X / 失败 Y` + 退出码表达），
且一键回归汇总行显示 `合计 N/N 项套件通过`，方可签署验收。
